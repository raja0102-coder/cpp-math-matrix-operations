# Sem 2 Engineering Mathematics: C++ Matrix Engine

A C++ object-oriented application implementing linear algebra matrix operations with operator overloading for Semester 2 Engineering Mathematics.

## Mathematical Concepts Covered
* **Matrix Representation**: Encapsulating 2D arrays using dynamic `std::vector` structures.
* **Operator Overloading**: Overloading `operator+` and `operator*` for natural mathematical syntax.
* **Matrix Transposition**: Swapping row and column indices.

## How to Compile & Run
```bash
g++ main.cpp -o matrix_engine
./matrix_engine
